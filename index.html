Machine Learning Project

Credit Card Fraud Detection using ML Classification

An end-to-end Machine Learning pipeline backed by a high-throughput FastAPI service.

Problem Statement & Objective

Credit card fraud represents billions in global financial losses every year. Due to severe class imbalance (legitimate transactions overwhelmingly outnumber fraudulent ones), typical models suffer from high false-negative rates. The goal was to build a disciplined classification system that reliably flags fraud while maintaining low latency in production.

Key Engineering Highlights

  • Data Cleansing: Identified and eliminated 1,081 duplicate records from the raw dataset to avoid distorted evaluation metrics.
  • Leakage-Free Partitioning: Implemented a stratified 3-way split: 170,235 training records, 56,745 validation records, and 56,746 test records to guarantee genuine generalization capability.
  • Model Evaluation: Optimized for high Recall and PR-AUC to catch suspicious transactions without overburdening manual review queues.
  • FastAPI Microservice: Built a lightweight REST API that accepts transaction payload JSON, executes inference in milliseconds, and returned verified HTTP 200 responses on comprehensive test suites.

Architecture & Technologies

Python Machine Learning FastAPI Scikit-Learn pandas NumPy Uvicorn

Data Analytics Project

Online Retail Business Analytics & RFM Segmentation

Customer segmentation and business intelligence dashboarding across 541k+ transactions.

Problem Statement & Objective

An online retail enterprise needed actionable visibility into their multi-national transactions to optimize marketing spend, retain high-value customers, and predict demand peaks across the calendar year.

Key Engineering Highlights

  • Big Dataset Wrangling: Ingested and scrubbed 541,909 retail invoice transactions spanning December 2010 through December 2011 using Python (pandas, NumPy) and MySQL.
  • EDA & Data Cleaning: Handled cancelled invoices, negative unit quantities, missing CustomerIDs, and currency conversions.
  • RFM Customer Segmentation: Built custom scores for Recency (days since last purchase), Frequency (total orders), and Monetary (total spent) to classify customers into tiers: Champions, Loyal, At-Risk, and Dormant.
  • Power BI Executive Dashboard: Created dynamic cross-filtering visualizations detailing monthly sales spikes, top 10 revenue-generating products, and international customer distributions.
